🏢 Complete Enterprise Network Design

3-Tier Architecture | 3 Floors | Full Services (DHCP, DNS, HTTP, Email, VoIP, File Sharing, AD)

📡 3 Routers 🖧 8 Switches 🖥️ 9 Servers 💻 12 PCs 📱 3 VoIP Laptops 📶 1 Access Point 🏷️ 8 VLANs
📋 Network Overview

This is a complete enterprise network designed for a 3-floor office building. Each floor has 4 wired PCs and 1 wireless VoIP laptop. The network includes full redundancy, security zones, and all essential business services.

⚡
High Availability

HSRP gateway redundancy
Dual uplinks to distribution
Automatic failover

🔒
Security Zones

DMZ for public servers
Firewall with ACLs
NAT for internet access

📡
Dynamic Routing

OSPF Area 0
Core router connects distribution
Automatic route updates

📱
Wireless VoIP

WiFi Access Point
Laptops connect wirelessly
Separate VLAN 60 for voice

📡 Step 4: Wireless Setup (VoIP Laptops)
4.1 Add WiFi Module to Laptops
  • Double-click VoIP-Laptop-F1
  • Go to Physical tab
  • Turn OFF the laptop (click the power button icon)
  • From the left side, find WPC300N (Wireless module)
  • Drag it to the empty slot on the laptop (usually the left side)
  • Turn ON the laptop
  • Repeat for VoIP-Laptop-F2 and VoIP-Laptop-F3
4.2 Configure Access Point
  • Double-click Access-Point
  • Go to GUI tab
  • IP Configuration: Set Static IP: 192.168.60.2, Subnet: 255.255.255.0, Gateway: 192.168.60.1, DNS: 192.168.40.11
  • Wireless → Basic Settings: Network Mode: Mixed, SSID: Company-VoIP, Channel: 6
  • Wireless Security: Security Mode: WPA2 Personal, Passphrase: voip123
  • Click Save Settings
4.3 Connect Laptops to WiFi
  • Double-click VoIP-Laptop-F1
  • Desktop → PC Wireless
  • Click Connect tab
  • Select Company-VoIP from the list
  • Enter password: voip123
  • Click Connect
  • Open Command Prompt → type ipconfig → Verify IP is 192.168.60.x
  • Repeat for VoIP-Laptop-F2 and VoIP-Laptop-F3
⚠️ Important: Make sure AP-SW port Fa0/24 is configured as VLAN 60 access port! This is covered in the Switch Configurations section.

5.2 Firewall Configuration (Router as Firewall)
Firewall (2911) - 3-Zone Security
enable
configure terminal
hostname Firewall

! === OUTSIDE ZONE (Internet) ===
interface GigabitEthernet0/1
 description OUTSIDE-to-ISP
 ip address 203.0.113.2 255.255.255.252
 ip nat outside
 no shutdown

! === DMZ ZONE (Public Servers) ===
interface GigabitEthernet0/0
 description DMZ-Public-Servers
 ip address 172.16.50.1 255.255.255.0
 ip nat inside
 no shutdown

! === INSIDE ZONE (Corporate Network) ===
interface GigabitEthernet0/2
 description INSIDE-to-Core-Router
 ip address 10.0.0.1 255.255.255.252
 ip nat inside
 no shutdown

! === ACL for OUTSIDE (Internet) ===
ip access-list extended OUTSIDE-IN
 remark Allow established connections
 permit tcp any any established
 permit icmp any any echo-reply
 remark Allow inbound SMTP to Mail Server
 permit tcp any host 203.0.113.10 eq 25
 remark Allow inbound HTTP/HTTPS to Web Server
 permit tcp any host 203.0.113.11 eq 80
 permit tcp any host 203.0.113.11 eq 443
 remark Allow inbound DNS queries
 permit udp any host 203.0.113.12 eq 53
 deny ip any any log

! === ACL for DMZ ===
ip access-list extended DMZ-IN
 permit tcp 172.16.50.0 0.0.0.255 any eq 25
 permit tcp 172.16.50.0 0.0.0.255 any eq 80
 permit tcp 172.16.50.0 0.0.0.255 any eq 443
 permit udp 172.16.50.0 0.0.0.255 any eq 53
 deny   ip 172.16.50.0 0.0.0.255 192.168.0.0 0.0.255.255 log
 deny   ip 172.16.50.0 0.0.0.255 10.0.0.0 0.255.255.255 log
 permit ip 172.16.50.0 0.0.0.255 any

! === NAT Configuration ===
ip access-list standard NAT-INTERNAL
 permit 192.168.0.0 0.0.255.255
 permit 10.0.0.0 0.0.0.3

ip nat inside source list NAT-INTERNAL interface GigabitEthernet0/1 overload

! Static NAT for DMZ servers
ip nat inside source static 172.16.50.10 203.0.113.10
ip nat inside source static 172.16.50.11 203.0.113.11
ip nat inside source static 172.16.50.12 203.0.113.12

! === Routing ===
ip route 0.0.0.0 0.0.0.0 203.0.113.1
ip route 192.168.0.0 255.255.0.0 10.0.0.2
ip route 10.1.0.0 255.255.255.0 10.0.0.2

! Apply ACL to interface
interface GigabitEthernet0/1
 ip access-group OUTSIDE-IN in

interface GigabitEthernet0/0
 ip access-group DMZ-IN in

end
copy running-config startup-config
