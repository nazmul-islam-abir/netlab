📝 Step-by-Step Implementation

1Set Up the Topology

Add devices to workspace:

  • 1 Router 2911
  • 4 Switch 2960-24TT
  • 9 PCs (PC0 through PC8)
💡 Connect all switches to Router's GigabitEthernet0/0 using trunk links (Router-on-a-Stick).
2Create VLANs on All Switches
Switch> enable
Switch# configure terminal
Switch(config)# vlan 10
Switch(config-vlan)# name student
Switch(config-vlan)# exit
Switch(config)# vlan 11
Switch(config-vlan)# name teacher
Switch(config-vlan)# exit
Switch(config)# vlan 12
Switch(config-vlan)# name staff
Switch(config-vlan)# exit
Switch# show vlan brief → VLANs 10, 11, 12 appear as active
3Configure Access Ports for PCs
Switch(config)# interface fastEthernet 0/1
Switch(config-if)# switchport mode access
Switch(config-if)# switchport access vlan 10
Switch(config-if)# no shutdown
Switch(config-if)# exit
Switch(config)# interface fastEthernet 0/2
Switch(config-if)# switchport mode access
Switch(config-if)# switchport access vlan 11
Switch(config-if)# exit
4Configure Trunk Ports (Switch-to-Router)
Switch(config)# interface fastEthernet 0/4
Switch(config-if)# switchport mode trunk
Switch(config-if)# switchport trunk allowed vlan 10,11,12
Switch(config-if)# no shutdown
5Configure Router-on-a-Stick (Sub-Interfaces)
Router> enable
Router# configure terminal
Router(config)# interface gigabitEthernet 0/0
Router(config-if)# no shutdown
Router(config-if)# exit

Router(config)# interface gigabitEthernet 0/0.10
Router(config-subif)# encapsulation dot1Q 10
Router(config-subif)# ip address 200.200.200.1 255.255.255.248
Router(config-subif)# exit

Router(config)# interface gigabitEthernet 0/0.11
Router(config-subif)# encapsulation dot1Q 11
Router(config-subif)# ip address 200.200.200.9 255.255.255.248
Router(config-subif)# exit

Router(config)# interface gigabitEthernet 0/0.12
Router(config-subif)# encapsulation dot1Q 12
Router(config-subif)# ip address 200.200.200.17 255.255.255.248
Router(config-subif)# exit
Router# show ip interface brief → Sub-interfaces are up with IP addresses assigned
6Configure PC IP Addresses
  • PC0 (Student): IP: 200.200.200.2, Mask: 255.255.255.248, Gateway: 200.200.200.1
  • PC1 (Teacher): IP: 200.200.200.10, Mask: 255.255.255.248, Gateway: 200.200.200.9
  • PC2 (Staff): IP: 200.200.200.18, Mask: 255.255.255.248, Gateway: 200.200.200.17
  • PC3 (Student): IP: 200.200.200.3, Mask: 255.255.255.248, Gateway: 200.200.200.1
  • PC4 (Teacher): IP: 200.200.200.11, Mask: 255.255.255.248, Gateway: 200.200.200.9
  • PC5 (Staff): IP: 200.200.200.19, Mask: 255.255.255.248, Gateway: 200.200.200.17
  • PC6 (Student): IP: 200.200.200.4, Mask: 255.255.255.248, Gateway: 200.200.200.1
  • PC7 (Teacher): IP: 200.200.200.12, Mask: 255.255.255.248, Gateway: 200.200.200.9
  • PC8 (Staff): IP: 200.200.200.20, Mask: 255.255.255.248, Gateway: 200.200.200.17
