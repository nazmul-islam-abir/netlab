🛠️ Troubleshooting Branch VLANs

  • No inter‑VLAN ping: verify ip routing on br3560 and SVI status (show ip interface brief).
  • Trunk not working: show interfaces trunk on both br3560 and access switch – allowed VLANs must match.
  • PC cannot reach gateway: check switchport access VLAN (show int fa0/x switchport) and port status.
  • Branch router can't ping br3560: verify IP on Gig0/0 (192.168.100.1/30) and cable connection.
